# Followers Lie — build spec (7s viral loop)

**Angle:** Myth-bust — followers don't pay, a converting site does
**Business:** Follower Chasers
**Hook:** FOLLOWERS?! / DON'T PAY?! / THIS DOES?!
**Punch:** YOU NEED / THIS

1080 × 1920 · 30 fps · 7.000 s · no music (VO + foley SFX only) ·
word-by-word captions throughout · seamless loop (frame 209 = frame 0).

## Shot script
- **0.00–2.50 Hook.** Plate A push-in, hook slam from frame 1, shake +
  highlight re-punch, flash + whip hit on the slam.
- **2.50–6.60 Punch.** Plate B, sticker slam + CTA pill + handle,
  speed-line rush + flash + whip hit on entry.
- **6.60–7.00 Loop hold.** Plate A frozen at the exact frame-0 state,
  ping sting + flash decayed by 6.71 — loops clean.

## Voice
Two salesman lines:
- `a-open` 0.15s — Followers don't pay YOU!
- `a-angle` 2.55s — You need buyers, not likes. DM PROOF right now!

## Why it creates the need
10K followers. Zero sales. Sound familiar? 🎈

Seven seconds, one pain, one fix, one action. Built to be rewatched:
the loop restarts the hook before the thumb can scroll.
