# Storylines

The creator supplied a shot-by-shot storyboard, so this is the picked storyline.
The other two are kept as words only, in case a later turn wants to switch.

## A — "The five-minute fix" (PICKED, built)

**Device:** a moment in someone's day, told as one cause-and-effect chain.
**Form:** handheld vertical coverage that cuts on the object that opens the next
shot (phone → laptop → phone notification → cup → handshake → selfie).
Reda walks into a café that is losing customers, builds the owner a website in
five minutes, and the first order pings before the owner can argue. The viewer
ends up wanting the same result for their own business.
**First two seconds:** a tracking shot is already moving through the crowded
café, a barista calls "Behind you!", Reda sidesteps, and the hook line pops in
the upper safe zone from frame 1.
**Beats:** hook → skeptical owner → website → realization → order ping → full
café → handshake/hug → DM "FREE" CTA → end card → loop.
**Look:** hand-painted anime café, cream/black/dark-green, warm golden window
light, 6% grain, bold cream word-by-word captions.
**Sound:** no music; natural café room tone, overlapping conversational voices,
exact SFX on visible actions.

## B — "The empty chair" (not built)

**Device:** life before/after on one object — a single empty café chair.
**Form:** one locked-off frame that rebuilds itself (the same chair, then the
same chair with a customer, then a queue at the door), with type carrying the
argument. More graphic, less human; loses the character performance.

## C — "The search" (not built)

**Device:** the feature as the hook — a phone search for "coffee near me" that
returns nothing, then returns the café.
**Form:** an endless zoom into the phone screen and back out into the café.
Stronger product demo, weaker story; no owner, no handshake, no hug.
