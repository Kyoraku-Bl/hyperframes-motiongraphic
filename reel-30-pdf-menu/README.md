# A PDF in 2026?!

Editable HyperFrames HTML composition for an 18-second vertical Reel.
Business: **Café Verona**. Marketing angle: **Menu friction — a broken PDF menu sends diners next door**.

Open `index.html` / this folder in the HyperFrames desktop app, or run
`npx hyperframes play .`. Validate with `lint` + `check --json`, export with
`render . -o reel.mp4 -f 30`. Publish kit: `python tools/make_delivery.py`
produces `delivery/` (cover, caption, hashtags, MP4) and a ZIP.

See `SPEC.md`, `REVIEW.md` and the shared `STYLE.md` for the full contract.
